# Support

- **Using the keyboard:** start with the [package guide](packages/saccade-keyboards/README.md) for the options, and the README of the language package you installed, for example `packages/saccade-fr/README.md`.
- **Questions and ideas:** open an issue and choose the feature request form, or ask in [GitHub Discussions](../../discussions) if it is enabled.
- **Bugs:** open an issue with the bug report form. Name the package and its version, the language, arrangement and region, and the width of the keyboard. A screenshot helps.
- **A wrong or missing key:** use the layout fix form, and link to the official layout or a photo of a real keyboard.
- **A new language or region:** use the new language or region-specific layout form.
- **Security problems:** see [SECURITY.md](SECURITY.md).
